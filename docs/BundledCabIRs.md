# Bundled cabinet IRs (`Assets/IRs/`)

Three cabinet impulse responses ship inside the app binary (embedded via the
`OpenGuitarMultiFx_IRs` binary-data target, same mechanism as the fonts and
icons). They exist so every physically-modelled amp gets a real cabinet
response out of the box — the Oct-2026 audit found the amps emit raw
power-amp output (bright/harsh) unless the user manually adds a Cab block and
loads an IR file, and a fresh install had no IR files at all.

## What they are (and are not)

They are **synthetic "house curve" IRs**, generated by
`tools/gen-cab-irs.py` — the impulse response of a small cascade of
analog-style filters plus a faint early-echo comb for cone-edge diffraction.
They are **not** measurements of real cabinets and contain **no third-party
IR material**, so there are no licensing questions about shipping them. The
trade-off is deliberate: they're plausible generic cabinet curves, not
clones of a V30/G12H/etc. (same "-Style, not the trademark" convention as
the pedal names).

| File | Selector name | Curve | Length |
|------|---------------|-------|--------|
| `cab-4x12-closed.wav` | Built-in: 4x12 Closed-Back | HP 75 Hz, +4 dB @ 100 Hz box bump, +2 dB @ 2.7 kHz presence, 4th-order LP 5.2 kHz | 45 ms |
| `cab-2x12-open.wav`   | Built-in: 2x12 Open-Back   | HP 95 Hz, +2.5 dB @ 125 Hz, +1.5 dB @ 2.5 kHz, 4th-order LP 6.2 kHz | 35 ms |
| `cab-1x12-open.wav`   | Built-in: 1x12 Open-Back   | HP 110 Hz, +2 dB @ 150 Hz, +2 dB @ 3 kHz, 4th-order LP 6.8 kHz | 30 ms |

48 kHz, stereo (same capture on L/R, like one close mic), 24-bit PCM.
Regenerate with `python3 tools/gen-cab-irs.py` (pure stdlib).

## How they're selected

`IRLoaderProcessor` ("Cab" role only — bundled cabs are meaningless for the
Reverb role) and `DynamicCabProcessor` each gained an integer **IR Source**
parameter appended after the existing params (order untouched, so old
presets are unaffected):

- `0` = **File** — the IR loaded via Browse/TONE3000 (`loadModelFile`),
  exactly as before. Loading a file automatically points the selector here.
- `1..N` = **Built-in:** entries, loaded straight from binary data — no
  external file needed.

A new "Cab" block defaults to `Built-in: 4x12 Closed-Back` (Dynamic Cab: IR
A bundled, IR B empty so single-IR behaviour is unchanged). The setting is a
normal float parameter, so presets, MIDI Learn and the RenderFx tool all
handle it with no extra code.

## Realtime safety

Loading (built-in or file) happens **only on the control thread** — in
`prepare()`/`setState()`/`applySourceSelection()` (polled by the existing
100 ms sweep timer, which is how a UI change to the selector reaches it) —
never in `process()`. The audio thread only ever reads the current
`juce::dsp::Convolution` pointer via the `DeferredReclaimer` atomic swap,
the same discipline NAM model loading already uses.

## Preset compatibility

- Presets saved before this feature have no `ir_source`/`dyncab_source_*`
  attribute → their file-or-nothing meaning is preserved exactly (selector
  pinned to "File").
- New presets store the source parameter like any other knob plus the usual
  `irPath` attribute; an explicit bundled selection wins over a stale
  `irPath`.
