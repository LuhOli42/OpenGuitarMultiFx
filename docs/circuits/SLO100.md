# SLO-100-Style Amplifier

A component-level model of the **Soldano SLO-100** ("Super Lead Overdrive 100"), built from the factory schematic
("March 15, 1996", schematicheaven.net, 8-page PDF). Only the **OD (Overdrive) channel** is modelled — the Clean
channel (switched by VR1/VR4 optoisolators on the real amp) is not implemented, following the same convention as
the JCM800's second channel or the AC30's Normal channel. The FX Send/Return loop is not modelled (standing
project rule: never model effects loops).

Display name: **SLO-100-Style Amplifier** (trademark-safe convention).

## Architecture

### Preamp — five cascaded 12AX7 sections

The SLO-100's OD channel has more cascaded gain stages than any other amp on this project's roadmap:

1. **V1b** (Sheet 1): 68K stopper resistor, 1M grid leak, 220K plate load from the B4 rail (~359V),
   1.8K cathode with 1 µF bypass cap. The input is a standard guitar-input stage.
2. **OD Volume** (500K audio-taper pot): the preamp's own gain control, between V1b's plate and V2a's grid.
3. **V2a** (Sheet 1): 470K grid leak from the OD Volume wiper, 100K plate load from the B3 rail (~350V),
   1.8K cathode with 1 µF bypass.
4. **V2b** (Sheet 1): **.001 µF (1 nF) coupling cap** — a defining voicing component that rolls off bass going
   into the high-gain stages. 100K mixing resistor, 1M grid leak, 100K plate load from B3, **39K unbypassed
   cathode** — this strong local negative feedback is the SLO-100's characteristic tight, articulate distortion.
5. **V3b** (Sheet 1): .02 µF coupling, 220K grid leak, 220K plate load from B2 (~378V), 1.8K cathode
   with 1 µF bypass.
6. **V3a** (Sheet 1): cathode follower — its output feeds the tone stack. The follower's DC offset is measured
   during `buildChannel()` and subtracted (two-pass).

### Tone stack — Fender-style TMB

Standard passive TMB: 47K slope resistor, 470 pF treble cap, .02 µF bass/mid cap, Treble 250K, Bass 1M, Mid 25K.

### Phase inverter — 12AX7 long-tailed pair

.02 µF coupling caps, 1M grid leaks, 82K/81K plate loads, 470Ω tail resistor, 47 pF between plates (Miller),
10K tail to ground.

### Power stage — 4 × 6L6GC push-pull, fixed bias

.047 µF coupling caps, 1.1K grid stoppers (2.2K/2 per pair), 220K grid leaks, 100K + 220K bias network from
a -70V bias supply. Screen resistors 475Ω per pair. The output transformer primary half-inductance is 3.0H,
turns ratio 6.25:1 (half to secondary).

### Global negative feedback with Presence

The real amp takes NFB from the 4Ω tap through 39K + 4.7K (= 43.7K). This model uses the 16Ω secondary tap,
so the feedback resistor is scaled: 43.7K × 16/4 = **175K** to deliver the same feedback current. Presence is
a 25K pot with .1 µF cap. A 1.5 nF stray capacitance is in the feedback path for closed-loop stability with
the inductive speaker load (same pattern as every other amp in this project).

### Power supply

Solid-state rectification (diode bridge, not a tube rectifier): rectifier resistance 60Ω. 497V nominal plate
rail. Choke-filtered chain of six supply nodes (sA plates, sB screens, sC PI, sD/sE V2/V3, sF V1).

## Simplifications

- **Bright input**: the real amp has a 470 pF bright cap across an input-jack switching arrangement. This
  model uses a simple 1.4× gain factor when "Bright" is selected, rather than modelling the cap's frequency-
  dependent response (a reasonable approximation for a small-value cap whose knee is well above the guitar's
  fundamental range).
- **FX loop stages V4a/V4b skipped**: signal goes directly from the V3a follower to the tone stack.
- **Power Drive placement**: applied between preamp output and tone stack (same convention as the JCM800).
  The real amp's OD Master Volume sits between the tone stack and PI, but since the tone stack is a linear
  passive network, the frequency response is identical regardless of placement.
- **No Clean channel or channel switching**.

## A power-stage instability

Same pattern as the JCM800: the full-topology reference model self-oscillates from silence (10s peak ~1.0
without any softening). The established "split kg1 across both tubes" fix was applied:

- **10×**: still oscillates (peak 0.18)
- **30×**: marginally stable (peak 0.018, just above the 0.01 test threshold)
- **40×**: genuinely stable (peak < 0.01, 10s soak clean) ← **shipped value**
- **70×**: stable, but collapses gain to ~0.1 Vrms (same as JCM800's ~100× collapse)

At 40× the reference model's own gain is still severely collapsed: ~0.4 Vrms where a healthy 100W 6L6GC amp
should reach ~60 Vrms (a ~42 dB gap). Following the JCM800 lesson: **the reduced-order power stage keeps the
Twin Reverb's own fitted 6L6GC constants** (same tube type, same push-pull topology) rather than calibrating
against this unreliable reference. The reference-tracking test is replaced with a "finite output, zero failures"
check on the reduced-order path only.

Registry trim: **-18.92 dB** (measured via `PedalUnityLevelTests`).

## Reduced-order power stage

Uses the Twin Reverb's fitted constants as placeholders:
- `bmGain0 = 9.5`, `bmYmax = 0.198`, `bmKneeN = 6.0`
- `bmShelfHz = 90.0`, `bmShelfHfGain = 0.55`
- Sag table: Twin Reverb's own data scaled to 497V

Cost: **~12.9% avg / ~19-22% worst block** — the highest of any amp on the roadmap, driven entirely by the
5-stage preamp's Newton solve cost (the reduced-order power stage itself is ~0% by definition). Zero failures,
zero recoveries.

## Controls

**Page 1**: Input (Normal / Bright), Gain (OD Volume, 500K), Treble, Mid, Bass, Presence, Output.

**Page 2**: Power Drive, Bias, Tube Feel, Speaker (4 / 8 / 16 ohm).
