# 5150 Amplifier (key `EVH5150StyleAmplifier`)

Processor: `Source/Effects/EVH5150StyleAmplifierProcessor.{h,cpp}`.

## Source

The factory Peavey EVH 5150 schematic, 5 pages (thetubestore.com, `Peavey-EVH5150-Schematic.pdf`): initial preamp,
intermediate preamp, tone stack / PI, output section, and the whole amp on one sheet. Kept locally in
`~/schematics-audit/5150/`, not in the repo.

The first version of this model was built from the same PDF but placed several parts in the wrong stage. It had:

- R29 470K to ground, where the schematic has it in series;
- a 39K series resistor into V2A and a 10K unbypassed cathode on V2B, where V2A has the 39K cathode;
- a 1M / 100K "stopper / leak" on V5B, where they are a divider;
- V5A as a cathode follower, where it is a gain stage with plate-to-grid feedback;
- a 33K slope resistor, 1K + 10K tail, 75 pF across the PI plates and R48 left out as "cross-coupling".

With so many stages off, the shipped path had grown compensation on top: an extra 3.5x input drive, two shelving
filters and a lift on the master. All of that is gone. The model below follows the schematic.

### Rhythm channel

K2A takes the CLEAN pre network instead (C6 → R19 470K ∥ C51 270p → R21 1M → VA1 1M with C27 180p), K1B puts R20 220K
on V2A's grid (Crunch off), and K2B takes CLEAN POST. All the gain stages stay in the path, as in the real amp. The
earlier model bypassed V2A and V2B for Rhythm, which the schematic does not do.

### Interpretation

- **C18.** Both drawings of the tone stack (page 3 and the whole-amp sheet) have a line from HIGH's bottom straight
  down to LOW's top, across C18. Read literally, the bass cap is shorted. The model treats that line as a drafting
  slip and puts C18 between the slope node and HIGH's bottom / LOW's top: the usual TMB, and the only reading that
  gives LOW a capacitor.
- **K4A / K1 / K3 voicing paths left out:** C13 470p / R43 2.2M, C10 470p / R75 2.2M (DRASW), R23 39K + C63 .1 (K4B),
  V1B's C26 22µ + R18 47K leg (in series with 47K it changes nothing above a few hertz), and the loop's C53 / C65 .33
  (a ~3 Hz high-pass).
- **Supply.** Page 4 feeds the OT centre tap from the node after R210 400 Ω and the screens from the node before it. The
  model keeps the earlier order (plates on the main node, screens after R210); the standby switch sitting between the
  two nodes makes the drawing hard to read with confidence.

## Solver blocks

The preamp is cut where a big resistor separates the stages. Each upstream block carries a passive copy of the next
block's input network as its load. The downstream block is driven by the upstream node.

| Block | Contents | Load copy |
|---|---|---|
| A | input, V1A, both pre networks, K2A, R82, V1B | C2 / R6 / R9 (exact: V2A draws no grid current) |
| B | V2A, V2B | R32 / C57 / R101 |
| C | V5B | R87 / C56 into ~40K (V5A's grid through its feedback) |
| driver | V5A, C58 / R88 | R89 into R24 and C59 / R94 |
| stack | tone stack, posts, loop resistors, C11 / R26 (linear) | — |
| power | V3A; in the full reference also the PI, power stage, OT, speaker and NFB | — |

`reducedOrder` (the shipped path) keeps every preamp block and V3A. It replaces the PI and power stage with the shared
behavioural stage, driven from C49 into the PI's 1M and scaled by Power Drive.

## Verification

- **DC:** V1A 172 V, V1B 230 V, V2A 317 V on a 327 V rail (the cold clipper), V2B 192 V, V5B 205 V, V5A 268 V, V3A
  310 V, PI tail 46 V, bias −48.5 V.
- **NFB sign:** closing the loop lowers the small-signal gain by 4.7 dB (test).
- **Reduced vs full:** level 0.18 dB, worst band 1.34 dB at rms 0.03 and 0.40 (bound 2 / 2; was 12 / 3).
- **Gain:** saturated from 0.02 V input at Gain noon; the output stays within 0.4 dB from 0.02 V to 1 V.
- **Stability:** silence, pluck and stress runs have no solve failures.
- **CPU:** 19.4% playing / 10.4% silent (EffectCostBench), against 9% before. The difference is the four triodes the old
  shipped path left out.

## Controls

Page 1: Channel (Rhythm / Lead), Gain, Low, Mid, High, Volume (the channel's Post), Presence, Resonance. Gain, the tone
controls and Volume are kept per channel (`ChannelKnobMemory`). Page 2: Power Drive (default 1 = the real amp; it is a
1M pot in place of R50, so turning it down attenuates what the PI sees), Bias, Tube Feel, Speaker, Output, Cab.
