## New flags

1. **EL84-family default levels collapsed.** unity at default knobs:
   HotCat30 +14.7→−5.5 (−20 dB), MatchlessHC30 +13.8→−4.5 (−18 dB),
   DividedBy13FTR37 +15.7→+4.2 (−11 dB), EVH5150 +20.4→+12.6 (−8 dB).
   Real audio-taper pots (#83) at 0.4–0.5 defaults legitimately deliver
   less gain than linear — probably mostly intended — but three amps now
   sit *below* unity at defaults, so PedalUnityLevel trims should be
   re-derived. Ear check attached (Matchless is quiet but voiced fine).
2. **`f37_ch1_volume` is a dead knob.** Swept 0.1→0.9 on the sine220
   probe: −19.62 vs −19.70 dB (Δ <0.1 dB). `f37_ch2_volume` works
   (−29.6→−18.7 dB across the same sweep). Already dead in the Oct-11
   run (its crunch variant measured identical to default then too), so
   pre-existing — but the audit `AMPS` crunch recipe uses
   `f37_ch1_volume=0.85`, which is why FTR37's crunch row duplicates
   default. Real wiring defect in the mini-netlist (#82/#83 area).
3. **`hc30_volume1` is inert on the default channel.** MatchlessHC30
   default `hc30_channel=1` routes the "channel two" path — volume2
   sweeps fine (−17.2→−4.2 dB), volume1 does nothing. On channel 0 both
   volumes are live. So the audit crunch recipe (`hc30_volume1=0.85`)
   duplicates the default render too — worth fixing the recipe to
   `hc30_volume2=0.85` (or channel 0) so the variant actually measures
   something.
4. **Systematic top-end darkening.** band6 (8–20 kHz band delta vs DI)
   fell hard on several amps: MatchlessHC30 +6.8→−55.9, AmpegB15
   −2.8→−49.7, SunnModelT −7.9→−30.2, HotCat30 +36.6→−19.5, AmpegV4B
   +0.2→−22.3, TwinReverb +1.2→−12.2, RiveraKnucklehead +6.1→−9.9.
   The built-in cab voicing (#65) + presence rework (#72) clearly moved
   the >8k region down. Absolute energy up there is small, but −50 dB
   swings are worth a listen.
5. **RiveraKnucklehead harmonic restructure.** sine220 THD 0.53%→4.0%
   (×7.6), even:odd 1.59→0.10 — the per-component curves (#63) gave it
   real asymmetric distortion at defaults. Probably a fix (a Soldano
   should not measure 0.5% THD into a 0.3 V sine) — ear check.
6. **DividedBy13FTR37 even-dominant.** even:odd 0.05→2.63 on both sine
   probes — same signature class as AC15.
7. **Trainwreck harmonic restyle.** even:odd 1.28→0.72 (sine220),
   0.08→1.94 (sine110); THD 49.9→36.6% crunch. Expected fallout of the
   new behavioral power stage (#78) — flag for ears, not code.
