# fx-audit delta report — 2026-10-11

Re-ran the full fx-audit sweep on `main` (36868a4) after the diode/BJT
re-parametrization, op-amp rail saturation, reducedOrder OT/speaker/cab
voicing, Mark IIC+ EQ, knob folds, and the new amp/pedal batch.
`tools/fx-audit/metrics.json` is refreshed to the new measurements.

Coverage grew: 123 registered effects (was 94 in the Oct sweep),
232 DI renders, 477 probe renders, drive sweep now includes the
`bassdrive` family (Darkglass B7K / ODB-3 / SansAmp BDDI) plus
BassBigMuff and TS9B in `muff`/`ts`.

## Methodology note — DI level confound (important)

The Oct-2026 baseline was measured against a hotter DI than the one now
committed: identical take, but +16.2 dB (peak 0.5 vs 0.077, same band
profile). A 16 dB hotter input drives every nonlinear stage far harder,
so a naive old-vs-new diff is dominated by input level, not code.

All "before vs now" numbers below therefore come from a second render
pass with the DI re-gained to the Oct level (peak 0.5) — like-for-like.
The stored `metrics.json` uses the committed (quiet) DI, matching what
`run_renders.py` produces by default. Probes (sine/sweep/clicks) were
unchanged between runs, so probe deltas were already clean.

## What improved

1. **NAM path fixed.** NeuralAmp / NeuralAmpCab / NeuralPedal previously
   had a −23.1 dB hole at 3.2–8 kHz and ran ~22 dB under unity. Now
   −0.6 dB in that band, at unity level (sweep-FR at 1.5 kHz −22.8 → −0.4 dB).
2. **JTM45 / Bassman default-drive THD more than halved.**
   JTM45 sine220 35.2% → 7.0%, sine110 31.4% → 8.5%;
   Bassman sine220 30.3% → 6.1%, sine110 28.7% → 6.3%.
   even:odd moved 0.008 → ~0.3 — from hard-symmetric clipping to
   asymmetric tube-like harmonic structure.
3. **Hard clipping eliminated.** PositiveGroundBooster (+hot) clip_frac
   0.048 → 0.000; SqueezerStyleCompressor no longer clips (was in the
   Oct clipping list).
4. **JC120 audible.** Was ~24 dB down in 120–400 Hz and near-inaudible;
   now flat band deltas and +31 dB louder output. Same family of fix as
   the amp+cab level normalization below.
5. **Amp + cab chains levelled.** Every `*-cab` render gained ~10–16 dB
   toward unity (AC15 +10.8, AC30 +14.6, EVH5150 +15.8, ENGL +14.0,
   SLO100 +12.8, Rockerverb +12.9, JCM800 +11.9, IIC+ +11.7, Twin +11.1,
   Deluxe +11.0, DualRect +12.0, JC120 +31.3) — the reducedOrder OT/
   speaker/cab work stopped the cab stage from crushing the level.

## Regressions to fix

Flagged by the audit thresholds (band delta moved >2 dB, THD doubled,
even:odd dominance flip, unity drift >1 dB). Most FR movement here is
the *intended* voicing change — the entries below are the suspicious
subset worth a listen rather than every moved band.

1. **EPStyleBooster lost its top end.** 8–20 kHz band +10.2 → −7.0 dB
   (17 dB darker); sweep-FR at 9 kHz +8.8 → −4.5 dB. A bright clean
   boost should not roll off that hard — check the rail/saturation
   stage is not killing the treble path. `EPStyleBooster-hot` also
   gained +10 dB at 20–120 Hz and still clips (0.003).
2. **Bassman / JTM45 got quieter.** unity −5.1 dB / −5.6 dB at default
   settings (crunch −1.4/−0.2). If PedalUnityLevel trims were meant to
   hold level, these two now sit low; also their top band collapsed
   (+10.7 → −5.2 dB, +17.6 → −4.9 dB) — verify that's intended damping
   vs a tone-stage bug.
3. **AC15 even:odd flip.** sine110/sine220 even:odd 0.46 → 1.3/1.08 —
   now even-harmonic dominant. May be intended (Vox chime), but it is
   the only polarity flip in the catalog, worth an ear check. Its
   8–20 kHz band also jumped −19.9 → −7.7 (crunch −2.5 → +7.3, cab
   −28.4 → +4.2): much brighter than Oct.
4. **High-gain amps got fizzier.** EVH5150 +15.0 → +24.9 dB and ENGL
   +14.5 → +19.4 dB in the 3.2–8 kHz band, while linear sweep-FR at
   12 kHz *dropped* (−9.3 → −24.6, −8.3 → −16.2). I.e. more nonlinear
   fizz energy over a darker linear top — plausible rail-saturation
   behavior but the sweep-FR drop may need presence-path retuning.
   SLO100 same signature (band +37 → +30, sweep-FR −6.8 → −17.2).
5. **TwinReverb crunch THD 1.2% → 12.3%.** Likely the reducedOrder
   power stage now actually saturates (the Oct 1.2% was suspiciously
   clean for tr_volume=0.9). Probably a fix, not a regression — but it
   crosses the "THD doubled" flag so it lands here for an ear check.
6. **New-amp clipping at hot input.** With the Oct-level DI several new
   amps exceed 0 dBFS in float: Acoustic360 crunch/cab clip 0.011/0.008,
   MatchlessHC30 cab 0.004, RiveraKnucklehead 0.002 (all variants),
   AmpegB15 cab 0.001, plus Matchless (−11 dB RMS, 11 dB hot) and
   Rivera/TraceElliot crunch well above unity. These need
   PedalUnityLevel trims.
7. **SansAmpBDDI measures as a linear EQ.** THD ~0.000002% at *every*
   drive setting 0.1–0.9 — the drive pot only moves the feedback
   resistor but nothing clips. Either headroom is unrealistically high
   or the nonlinear path is bypassed.
8. **SqueezerStyleCompressor −10.7 dB unity drift.** Now clean but far
   quieter than Oct — check its makeup gain.
