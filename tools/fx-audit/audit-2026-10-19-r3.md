# fx-audit round 3 — 2026-10-19 (main @ 2100ae1)

Full re-run of the fx-audit sweep on current main after the fidelity / CPU
merges (#90-#114) plus the compiled-pipeline and new-effect batches that
landed through 2026-10-19. **Measurement only — no DSP was changed.**
Fixes get their own sessions from this list.

Artifacts in this directory:

- `metrics.json` — refreshed (434 DI renders, 904 probe renders, drive sweep)
- `cpu-bench.csv` + `cpu-bench-2026-10-19-r3.md` — `RenderFx --bench`, 318/319 keys, 3 reps
- this file — summary + the generated delta tables (`delta_report.py`, below the fold)

Baselines compared against: `metrics.json` / `cpu-bench.csv` from #90
(`audit-2026-10-11-r2.md`, `cpu-bench-2026-10-11-r2.md`). Same DI on both
sides (`Tests/fixtures/di/guitar-di.wav`, peak 0.077 / rms −39.3 dBFS), so the
level/band columns are directly comparable.

## Harness change (coverage)

The catalog grew **123 → 319 keys** (flanger/delay/phaser/vibrato/chorus/octave/
synth batches, Multi-Type `Mt*_N`, Diezel VH4, Jim Kelley, Octavia, Super-Fuzz,
Tone Machine…). `run_renders.py` / `run_probes.py` had the Oct-11 key list
hardcoded and would have skipped the 196 new effects silently; both now append
every key from `RenderFx --list` (probes class new keys by name:
drive/amp → sine+sweep, compressors → dynamics set, everything else →
clicks+sweep). Crunch/hot recipes added for Diezel, Jim Kelley, Octavia,
Super-Fuzz and Tone Machine. `delta_report.py` (new) generates the tables below.

## CPU — read this first: box speed

This VM is faster than the one the Oct-11 table came from. Six effects whose
code did not change between the runs (Centaur, Blues Breaker, BD-2, Squeezer,
Dyna Comp, Overdriver) give a median eco ratio of **0.68**, so raw numbers
overstate every improvement by ~1.5x. `norm` columns = now / 0.68 (= the new
number on the old box). Unchanged-code effects still scatter by up to ~±4 pp
normalised (FuzzFace +4.2, Komet +4.3), so treat smaller moves as noise.

- Raw on this box: 24 → 9 effects over the 10 % eco budget. **Box-normalised:
  24 → 26** (the catalog grew and two regressions landed).
- **Real wins (normalised):** MetalZone 49.5 → 13.9, Bass Big Muff 26.8 → 8.0,
  Darkglass B7K 19.3 → 8.2, Big Muff 18.4 → 7.8, ODR-1 23.4 → 13.0,
  DT-1 21.8 → 11.7, Russian Muff 17.5 → 10.0, RAT / RAT2 / Turbo Rat ~11 → 6.6,
  SansAmp 5.0 → 2.3 — the compiled-pipeline pedals. Under budget even
  normalised: Bass Big Muff, Darkglass, Big Muff, RAT ×3 (Russian Muff on the
  line at 10.0).
- Not moved (normalised, within noise): HM-2 23.7, Tube Driver 21.3, Silicon
  Tone Bender 20.2, OCD 16.0, Sovtek Muff 15.5, DS-1 14.7, CrunchBox 14.0 —
  matches `docs/PerformancePipeline.md` (HM-2 / Tube Driver / DS-1 / CrunchBox /
  Tone Bender not applied to the pipeline; OCD applied but not cheaper here).

## Dead / silent / broken

No new effect renders silent or NaN on the DI. Flagged (details in the tables):

1. **`DiezelStyleAmplifier` + Cab clips hard**: crunch recipe (`dzl_channel=2
   dzl_gain=0.85`) through the 4x12 IR peaks at **3.44 (+10.7 dBFS)**, 20 % of
   samples clipped; crunch probe sine220 carries **DC +0.42**. New effect.
2. **`EchoplexStyleDelay`** sweep probe: 12 % clipped (peak 1.0, rms −4.9 dBFS)
   at default knobs (the DI render is clean, peak 0.32). New effect.
3. **`Whammy`** click probe renders **exactly zero** (−240 dB) while the DI and
   sweep renders are fine — the shifter emits nothing on impulsive input.
   `TrackedSynth` likewise near-silent on clicks (−118 dB; tracker never locks,
   probably expected). New effects.
4. DC offsets on new fuzzes: Tone Machine (up to −0.079 on sine110), Super-Fuzz
   (−0.039 at defaults), `SubOctaveSynth` sweep +0.117.
5. Small clip flags on new mod/delay sweeps (DC-2, Echo Flanger, Electric
   Mistress, Memory Man, OrganMachine, `MtDly_*` clicks) — ≤0.6 % of samples;
   `HotCat30` + Cab now touches 0 dBFS (peak 1.10).
6. `DividedBy13FTR37` crunch: new DC +0.026 (DI) and the 8–20 kHz band jumped
   **+51 dB** vs the Oct-11 render (see EQ shifts) — reads like aliasing/fizz,
   ear-check needed.
7. Inert recipe: `RiveraKnuckleheadStyleAmplifier-crunch` renders identical to
   default (recipe knob does nothing post-#103 — recipe or code, to triage).
